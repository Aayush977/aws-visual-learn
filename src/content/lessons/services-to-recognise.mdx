## Application integration

You met SQS and SNS in the scaling lesson. Two more complete the set:

- **AWS Step Functions** — coordinates a **multi-step workflow** as a state machine: do this, then
  that, retry on failure, branch if the answer was no. The answer whenever a question describes
  orchestrating several Lambda functions or services in order.
- **Amazon API Gateway** — a managed front door for APIs. Handles throttling, authorisation,
  caching and versioning, and is the usual way an HTTP request reaches a Lambda function.

<Callout type="exam">
<strong>SQS</strong> decouples one producer from one consumer group (each message consumed once).
<strong>SNS</strong> fans one message out to many subscribers. <strong>EventBridge</strong> routes
by rule, including events from AWS services and SaaS partners. <strong>Step Functions</strong>
sequences steps in order. The verb in the question — queue, broadcast, route, orchestrate —
picks the service.
</Callout>

## Developer tools

The **Code\*** family is a CI/CD pipeline broken into pieces:

| Service | Job |
| --- | --- |
| **CodeCommit** | Private Git repositories |
| **CodeBuild** | Compiles source and runs tests |
| **CodeDeploy** | Releases to EC2, Lambda or ECS, with rollback |
| **CodePipeline** | Chains the above into an automated release pipeline |
| **CodeArtifact** | Private package repository (npm, Maven, pip) |
| **AWS X-Ray** | Distributed tracing — where the latency actually went |

<Callout type="gotcha">
<strong>CodePipeline</strong> is the orchestrator; the others are the stages. A question about
"automating the entire release process from commit to production" wants CodePipeline, not
CodeDeploy. And <strong>X-Ray</strong> is the answer for "which microservice is causing the
latency", where CloudWatch only tells you that latency exists.
</Callout>

## End-user computing

- **Amazon WorkSpaces** — a fully managed virtual **desktop** in the cloud, reachable from any
  device. For remote staff, contractors, or regulated environments where data must not sit on a
  laptop.
- **Amazon AppStream 2.0** — streams a **single application** rather than a whole desktop. For
  delivering one heavy program, such as a CAD package, without installing it anywhere.

## Frontend, customer engagement and IoT

- **AWS Amplify** — build, deploy and host web and mobile front ends, with authentication and
  APIs wired in.
- **AWS AppSync** — managed **GraphQL** APIs with real-time data synchronisation.
- **Amazon Connect** — a cloud **contact centre**: phone numbers, call routing, agent interface,
  pay per minute. Frequently paired with Lex for self-service and Transcribe for call analysis.
- **Amazon Simple Email Service (SES)** — sending bulk and transactional email at low cost.
- **AWS IoT Core** — connects devices to AWS, manages their identities and shadows their state,
  and routes their messages onward.
